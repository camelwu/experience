# 亿企代账开发文档

## 一、系统概述

### 1.1 产品定位
亿企代账是为中小企业量身打造的基于互联网架构的综合应用平台，集票据、财务、报税、管理、服务为一体，支持工业成本核算、发票远程提取、自动生成凭证等功能。

### 1.2 技术架构
- **前端**：负责用户界面展示、交互逻辑处理，支持浏览器和微端两种访问方式
- **后端**：处理业务逻辑、数据存储、第三方系统对接（如税务系统、主流财务软件）

## 二、核心功能模块

### 2.1 系统登录模块

#### 前端开发任务
- 实现两种登录入口：浏览器访问（www.17dz.com）和微端访问
- 设计登录表单（账号/密码输入、记住密码选项）
- 集成验证码功能（防止暴力破解）
- 登录状态管理（Token存储、过期处理）

#### 后端开发任务
- 认证接口设计（POST /api/login）
- 支持旧账迁移的权限校验（需对接用友、金蝶等财务软件数据）
- 会话管理（Token生成与验证机制）
- 登录日志记录（IP地址、登录时间、设备信息）

### 2.2 记账流程模块

#### 前端开发任务
- **财务初始化界面**：
  - 建账月份选择器
  - 企业所得税征收方式选择（查账征收/核定征收）
  - 科目模板选择（小企业会计准则-商贸版等）
- **旧账迁移交互**：
  - 财务软件连接设置表单
  - 迁移进度可视化（进度条、状态提示）
- **凭证录入界面**：
  - 全键盘操作支持（快捷键映射如Ctrl+Q、Enter等）
  - 实时余额显示（减少录入错误）
  - 凭证模板管理（保存、调用、删除）

#### 后端开发任务
- **数据模型设计**：
  - 账套表（包含建账月份、企业类型等字段）
  - 科目表（支持辅助核算标记：客户/供应商/存货）
  - 凭证表（借贷方金额、记账日期、关联科目）
- **业务逻辑实现**：
  - 旧账迁移引擎（支持主流财务软件数据格式转换）
  - 凭证自动平衡算法（借贷方金额校验）
  - 辅助核算规则引擎（根据科目类型自动触发核算要求）

### 2.3 凭证处理模块

#### 前端开发任务
- 凭证列表页（支持按日期、凭证号、科目筛选）
- 凭证详情页（借贷方明细、附件上传区域）
- 批量操作功能（复制、删除、排序）
- 相似业务批量复制界面（选择源月份、筛选凭证范围）

#### 后端开发任务
- 凭证API接口：
  - GET /api/vouchers（分页查询）
  - POST /api/vouchers（新增凭证）
  - PUT /api/vouchers/{id}（修改凭证）
- 凭证排序服务（支持按记账日期重排、断号整理）
- 模板管理服务（保存凭证模板、批量调用逻辑）

### 2.4 期末处理模块

#### 前端开发任务
- 期末固定业务模板列表（工资计提、折旧、税金等）
- 结账流程引导页（结账检查项可视化）
- 反结账操作确认框（支持选择指定月份）
- 账务规范性自查结果展示（指标图表化）

#### 后端开发任务
- 自动结转服务：
  - 销售成本结转（支持百分比法/全月一次加权平均法）
  - 生产成本结转（产成品入库清单生成）
- 结账检查引擎（包含试算平衡、凭证完整性等校验规则）
- 反结账逻辑（支持跨月反向操作，数据回滚机制）

### 2.5 报表与税务申报模块

#### 前端开发任务
- 财务报表实时查询界面（资产负债表、利润表、现金流量表）
- 税务申报总览页（多税种状态可视化）
- 一键申报交互流程（数据预览、确认提交、进度反馈）
- 缴税界面（未缴税/已缴税状态切换、缴款方式选择）

#### 后端开发任务
- 报表生成引擎：
  - 实时数据聚合（无需结账即可生成报表）
  - 汇算清缴报表自动生成
- 税务对接服务：
  - 电子税务局接口封装（申报数据提交、反馈获取）
  - 发票数据自动提取（需对接金税盘）
- 银行对账单处理：
  - 对账单导入解析（支持Excel/Csv格式）
  - 流水自动生成凭证（收支类型智能匹配）

### 2.6 客户与收费管理模块

#### 前端开发任务
- 客户信息管理页（支持批量导入、搜索筛选）
- 合同管理界面（到期提醒、附件上传）
- 收费进度跟踪表（应收/预收/欠费状态标识）
- 对账审核表单（收费明细核对、状态标记）

#### 后端开发任务
- 客户数据模型：
  - 基础信息表（名称、税号、联系人等）
  - 服务项表（自定义服务项配置）
- 收费管理服务：
  - 代账费计算引擎（支持周期性计费）
  - 对账审核工作流（提交-审核-确认流程）
- 数据导入接口（支持Excel模板批量导入客户信息）

## 四、接口设计规范

### 4.1 认证接口
- **登录接口**：POST /api/auth/login
  - 请求参数：{username: string, password: string}
  - 响应参数：{token: string, expires_in: int, user_info: object}

### 4.2 凭证接口
- **查询凭证**：GET /api/vouchers
  - 请求参数：{page: int, page_size: int, date_range: string}
  - 响应参数：{total: int, items: voucher_array}
- **生成凭证**：POST /api/vouchers/generate
  - 请求参数：{type: string, data: object} （type可选值：'invoice', 'bank', 'inventory'）
  - 业务说明：支持发票、银行流水、存货出入库自动生成凭证

### 4.3 税务接口
- **一键申报**：POST /api/tax/submit
  - 请求参数：{tax_types: array, company_id: int}
  - 响应参数：{status: string, task_id: string}
- **获取申报反馈**：GET /api/tax/feedback
  - 请求参数：{task_id: string}
  - 响应参数：{status: string, message: string, data: object}

## 五、开发注意事项

### 5.1 前端开发要点
- 凭证录入界面需支持全键盘操作，快捷键需与文档一致（如Tab跳转单元格、Enter保存）
- 辅助核算选择界面需根据科目类型动态显示可选核算项（如应收账款显示客户核算）
- 报表查询页需支持实时数据刷新，无需等待结账

### 5.2 后端开发要点
- 旧账迁移模块需兼容用友、金蝶、航信等主流财务软件的数据格式
- 生产成本结转需实现全月一次加权平均法算法
- 税务申报模块需处理多税种并行申报逻辑，避免申报冲突

### 5.3 前后端交互规范
- 所有接口响应需包含标准格式：{code: int, message: string, data: object}
- 金额字段统一使用decimal(10,2)类型，避免浮点数精度问题
- 日期格式统一为YYYY-MM-DD，时间格式为YYYY-MM-DD HH:MM:SS

## 七、第三方系统对接

### 7.1 财务软件对接
- **对接范围**：用友、金蝶、航信等主流财务软件
- **后端接口设计**：
  - 数据迁移API：POST /api/import/finance
    - 请求参数：{software_type: string, file_path: string, mapping_rules: object}
    - 响应参数：{status: string, progress: int, error_list: array}
  - 数据格式转换服务：
    - 科目余额表转换（旧账格式→亿企代账格式）
    - 凭证数据映射（旧软件凭证字段→新系统字段）

### 7.2 电子税务局对接
- **对接流程**：
  1. 账号密码配置（前端提供设置界面）
  2. 报表数据自动提取（后端定时任务或触发式）
  3. 一键申报提交（支持多税种批量申报）
- **安全设计**：
  - 税务账号加密存储（AES-256加密）
  - 申报数据签名校验（防止篡改）

### 7.3 银行系统对接
- **对接方式**：
  - 对账单文件导入（支持标准格式）
  - 银行流水API对接（需银行开放接口）
- **数据安全**：
  - 银行账户信息加密传输
  - 对账单文件本地解析（不传输原始文件）

## 八、系统安全设计

### 8.1 前端安全
- 密码输入框加密（前端JS加密传输）
- XSS防护（所有用户输入做HTML转义）
- CSRF防护（请求携带Token令牌）

### 8.2 后端安全
- 接口权限控制（基于Token认证）
- 敏感数据加密（税务密码、银行账号等）
- 操作日志记录（关键操作全量留存）
- 数据备份策略（每日增量备份，每周全量备份）

### 8.3 数据安全
- 数据库字段加密（敏感字段如税号、密码）
- 数据传输加密（HTTPS协议强制要求）
- 备份数据加密存储（AES-256加密）

- 浏览器端：Nginx静态资源服务器（缓存HTML/CSS/JS）

2. 后端编译（）
