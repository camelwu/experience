# 伤寒
它将外感疾病及其发展过程分为六个阶段(即「六经」)，并根据各阶段的病理特点、临床症状与体质特征，制定相应的治疗原则(理、法、方、药)。  

首先，人体十二正经，手足各三阳三阴，经络之间有连通并有联动，按一天十二时辰的运行分别是：  

(子时23～1)足少阳胆经->(丑时1～3)足阙阴肝经->(寅时3～5)手太阴肺经->(卯时5～7)手阳明大肠经->(辰时7～9)足阳明胃经->(巳时9～11)足太阴脾经->(午时11～13)手少阴心经->(未时13～15)手太阳小肠经->(申时15～17)足少阴膀胱经->(酉时17～19)足少阴肾经->(戌时19～21)手少阳三焦经->(亥时21～23)手少阳三焦经。
## 六经辨证
六经辨证以阴阳为总纲，具体划分为六个层次：
+ 太阳病(阳证表证)：外感初期，邪在表。症见发热、恶寒、头痛、脉浮。  -- 体表
+ 阳明病(阳证里证)：邪热入里，正邪剧争。症见高热、汗多、口渴、脉洪大，或便秘、腹满痛。 -- 通道
+ 少阳病(阳证半表半里证)：邪在表里之间。症见寒热往来、胸胁苦满、口苦、咽干、目眩。 -- 循环
+ 太阴病(阴证里证)：脾胃虚寒。症见腹满而吐、食不下、自利益甚、时腹自痛。
+ 少阴病(阴证里证)：心肾阳虚或阴虚。症见脉微细、但欲寐(精神萎靡、嗜睡)。
+ 厥阴病(阴证半表半里证)：阴阳寒热错杂的危重阶段。症见消渴、气上撞心、心中疼热、饥不欲食、四肢厥冷。

這套體系的核心是將人體經絡與臟腑聯繫起來，將疾病分為**三陽**和**三陰**
## 治疗原则
### 三阳病(多屬表、熱、實證)
+ 太阳病：疾病初期，邪在体表。主要症状为脉浮、头项强痛而恶寒。
+ 阳明病：邪气入里化热，属里实热证。主要症状为身热、自汗、不恶寒反恶热。
+ 少阳病：病在半表半里。主要症状为往来寒热、胸胁苦满、默默不欲饮食、口苦咽干目眩。

### 三阴病(多属里、寒、虚证)
+ 太阴病：病在脾经，属里虚寒证。主要症状为腹满而吐、食不下、自利益甚。
+ 少阴病：病在心肾，属全身虚衰的阶段。主要症状为脉微细、但欲寐。
+ 厥阴病：疾病的最后或危重阶段，呈现寒热错杂。主要症状为消渴、气上撞心、心中疼热、饥而不欲食。

## 核心特点
动态观察：六经辨证不仅是分类，更描述了疾病从表入里、由轻转重的演变过程。
辨证施治：针对不同经别的病症提供对应方剂(如太阳经的麻黄汤、桂枝汤等)。
广泛应用：虽最初针对外感病(伤寒)，但后世医家将其应用于内科、妇科及杂病治疗。

邪浅正盛，治疗以祛邪为主，如太阳病发汗、阳明病清下、少阳病和解。
+ 三阴病：邪盛正衰，治疗以扶正为主，如太阴病温中散寒、少阴病温阳育阴。
