# 中医诊断学入门和临诊  

## 前言介绍

西医或现代医学的检测仪器非常多，能清晰的找出身体病灶；而中医(Traditional Chinese Medicine)诊断方法自古就只有四门功课：望、闻、问、切，那么为什么通过这四种方法就能知道患者的问题在哪里？中医诊断到底是做样子还是真的能诊断出问题？古人究竟是如何发现又是如何总结出来的？  

## 中医诊断的逻辑架构

将整个天地都看成一个整体，那么春、夏、秋、冬四季，就有对应的气候（24节气）、食物、环境。比如：春天植物生发，夏天炎热，秋天落叶，冬天寒冷。那么反过来看到落叶，是不是秋天到了，冬天快要来了？所以，我们通过植物、动物、温度、湿度、云等等的变化可以反推出天气和季节的变化。同理，在人身上，出汗代表热，发抖怕冷代表寒，看到红眼和黑眼圈是不是大概率这个人没睡好？故而通过人的面色、声音、体态、脉象等方面，我们也可以反推出人体的疾病。这就是中医诊断学的底层逻辑：“一体同源”。

将人体视为一个有机的整体，人体各个脏腑器官，各部分之间相互联系、相互制约（五行、寒热、阴阳），而且人体与外界环境之间也存在着密切的联系。中医学认为，人体疾病的发生、发展、转化、治疗，都受到人体内部和外部多种因素的影响。因此，中医诊断学在研究疾病时，不仅要考虑疾病本身的特点，还要考虑人体内部和外部环境的影响。（五运六气）

古人把体内的问题在脸色、声音、脉象等方面表现出来做了完善的总结《中医诊断学》；通过望、闻、问、切这四种方法，来观察和了解人体的病症，从而判断疾病的性质、程度和部位，为治疗提供依据。《扁鹊见蔡恒公》中扁鹊用的这就是中医的“望”这门功课，通过观察人体的面色、皮肤、掌心颜色、步态等，来判断人体的气血、脏腑功能的变化，从而判断疾病的性质、程度和部位。甚至后世医家不断努力，望还分出手诊、面诊、耳诊、舌诊等等。

为避免偏颇，中医诊断要求四诊（望、闻、问、切）合参，每个功课都是内部情况的外在表现，其中望、闻、切是医者从“外部”获取的信息，而“问”就是患者自身情况的具体表现。四个情况对照，才能辨“证”施治。

## 舌诊 上篇

学习目标：深刻理解“经络是内脏的延申，舌象是内脏的镜子”，建立通过舌象验证和深化理疗评估的思维。

### 第一讲：舌诊入门
中医认为：“有诸内者，必形诸外”。舌连接人体内外，也是人体脏腑气血以及功能状况的晴雨表，不易受到外界环境影响变化，能较为真实的反应机体内在情况与疾病状况，舌象是脏腑功能在舌面的反映，是脏腑功能活动的客观表现。在诊断中有非常重要的作用。

《素问·金匮真言论》：“东风生于春，病在肝，俞在颈项；南风生于夏，病在心，俞在胸胁；西风生于秋，病在肺，俞在肩背；北风生于冬，病在肾，俞在腰股；中央为土，病在脾，俞在脊。” [3]

《灵枢·脉度》：“脾气通于口，脾和则口能知五谷矣。”
后世医家（如元代杜清碧《伤寒舌诊》）明确提出舌象与脾胃消化功能的密切关系。

心开窍于舌，心脏的功能状态、气血的盛衰，会像“苗”一样显现在舌这个“窍”上。心火旺则舌尖红、生疮；心血瘀阻则舌质紫暗或有瘀斑。心能辨别是非（神志清明则能判断），舌用来表达言语、辨别味道。

“外候”即外在的表现。通过观察经络，舌头与心、脾直接相连。脾主运化，舌苔是由胃气蒸腾所生，犹如大地（脾胃）上生长的苔藓。舌苔的厚薄、润燥、颜色直接反映了脾胃功能（消化、水湿代谢）的状态。

2.1. 同源异流  
痰饮水湿本质上都是津液代谢异常，水不能被脾土运化，在哪里不动了就有了对应的名词。
痰：在肺就变成了痰。
饮：在胃就变成了饮。
湿：在脾就变成了湿，因脾本身就主运化，会将水带到全身各个地方，故全身水太多，如同穿了带水的棉衣，困、顿、乏力。

2.2. 气血津液  
人体消化过程：鼻->口腔->食道->胃(胆、心)->小肠（心、脾）->大肠（小肠、肺）->膀胱（肾）。
人体气机过程：左升右降，水火交济，任降督升，前阴后阳。
津液精微在体内流动，在肺就变成了痰，在胃就变成了饮，在脾就变成了湿。

3.  舌象与疾病类型、程度、部位的关系
